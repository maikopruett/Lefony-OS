# Boot-menu typography

Roboto variable font by the Roboto Project Authors, SIL Open Font License 1.1.
Source: https://github.com/google/fonts/tree/main/ofl/roboto

Bundled `Roboto.ttf` SHA-256:
`d7598e12c5dbef095ff8272cfc55da0250bd07fbdecbac8a530b9b277872a134`.
The exact input is retained here so builds do not depend on a moving URL or a
host-installed font. `OFL.txt` accompanies it. The build generates ASCII alpha
atlases at 12, 16 and 28 pixels using `scripts/generate_bootmenu_font.py`.
